Renderer Selbsttest

Dieser Test rendert echte Slides mit Fabric.js im Browser und prüft, ob die manuelle Position, der Layout-Wechsel und „the last one wins" korrekt funktionieren.

So führst du ihn aus: Im Projektordner npm run dev starten, dann im Chrome http://localhost:5173/renderer-test.html öffnen. Unten muss alles grün sein.
